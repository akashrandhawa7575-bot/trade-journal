Connect your ledger

Your trades are stored as a JSON file inside a GitHub repo you control, so the same journal loads on every device. Point this app at that repo below.

Create a fine-grained token at github.com → Settings → Developer settings → Personal access tokens, scoped to this one repo, with Contents: Read and write permission. The token is saved only in this browser's local storage — it is never sent anywhere except directly to GitHub's API.
